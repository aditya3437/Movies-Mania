# 🎬 Movies-Mania  

Movies-Mania is a React.js web app that lets you explore movies using the [OMDb API](https://www.omdbapi.com/).  
Search by movie name, browse results with pagination, and view movie details in stylish cards.  

---

## 🚀 Features
- 🔍 Search movies by title  
- 📄 Pagination support (10 movies per page)  
- 🎨 Modern responsive UI with dark/light mode  
- ⭐ Sort options (Date / Rating / Asc/Desc – optional to implement)  
- 🖼️ Movie cards with poster, title, year, and short details  

---

## 🛠️ Tech Stack
- **React.js** (Frontend)  
- **CSS3** (Styling)  
- **OMDb API** (Movie Data)
